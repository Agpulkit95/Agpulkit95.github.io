# Privacy policy for fitbit-air-mac

fitbit-air-mac is a personal tool used only by its author. It reads the author's own Google Health (Fitbit) data to show it on
the author's Mac. Data stays on that Mac; nothing is shared with anyone, sold, or sent to third parties.

Access can be revoked at any time at <https://myaccount.google.com/permissions>.

Contact: the author, via the GitHub profile this site belongs to.
